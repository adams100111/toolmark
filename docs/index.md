features:
  - title: One registry
    details: Tools, scopes, schemas (Standard Schema v1) and results live in a single framework-free registry with zero runtime dependencies.
  - title: Every caller
    details: The same declaration serves an in-app agent over bridge protocol v1, WebMCP, a paired desktop MCP client, tours and Playwright tests.
  - title: Safe by default
    details: Per-caller policy, deferred or inline confirmation for consequential tools, redaction of sensitive fields, and no code execution.
  - title: Forms first
    details: react-hook-form, Inertia, plain DOM forms and wizards become fill/submit tools that respect what the user typed.
  - title: Guided tours
    details: Authored or agent-planned tours in show, guide and do modes, with an accessible, themeable overlay and RTL support.
  - title: Lint
    details: toolmark lint checks the manifests your pages expose, with an optional TypeSafe judge for description quality.
